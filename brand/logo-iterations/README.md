# Stein Product logo iterations

Every logo round from the First Light brand work (2026-09-25), oldest first. All files are plain SVG with text outlined, so they open and edit cleanly in Figma, Illustrator or any vector editor. Open `overview.html` (or `overview.png`) to see them all at once. Each folder has a NOTE.txt explaining the round.

1. `01-first-sketch`: symmetric horizon with a centered sun. Rejected: read as a person icon.
2. `02-mark-explorations`: five standalone mark directions. A became First Light.
3. `03-first-light-v1`: first published logo, mark beside an Unbounded Medium wordmark.
4. `04-integrated-concepts`: the mark built into the name (Sunrise i, Planet o, Horizon arc, Stacked horizon) in three fonts, night and day, with icons.
5. `05-sun-over-i-studies`: spacing studies for the chosen Sunrise i direction in Anybody Expanded.
6. `06-final-first-light`: the Anybody Expanded version with the tilted mark over the i.
7. `07-round-three`: condensed wordmarks (five faces, sentence case and caps) with a symmetric orbital-sunrise horizon, for Horizon arc, Stacked horizon and Sunrise i, plus the new tile and porthole icons.
8. `08-round-four`: Barlow Semi Condensed. C as the signature lockup, A as the everyday wordmark (larger and widest horizon), tile and porthole icons, and flat versions for light backgrounds.
9. `09-anybody-condensed`: both logos in Anybody Condensed ExtraBold (width 75), same horizon and icons.

Colors used throughout: stein-teal #0E6B6B, aurora #34F5C5, sol #FFD98A, sun #FFF4D6, night ink #E8FBF6; day variants swap aurora for #0F9E80 and sol for #E8892F.
