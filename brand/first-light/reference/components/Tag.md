Mono, uppercase status and category label in a glass pill.

**Provide:** `children` (one to four words), optional `tone` (`neutral` | `aurora` | `sol` | `danger`), `dot` (static status dot), `live` (pulsing dot for something happening now).

- `aurora` + `live`: availability and live states ("Taking clients").
- `sol`: promises and time ("Live within a week"). One sol Tag per view.
- `neutral`: facts ("Fixed scope").
- `danger` always carries a word that says what is wrong.
- For a bare label above a heading, use the `sp-eyebrow` class instead of a Tag.
