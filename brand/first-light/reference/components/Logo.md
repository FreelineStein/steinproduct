The Stein Product wordmark, with First Light (the horizon and sun) forming the dot of the i, or First Light alone as the mark. Drawn inline so it scales crisply.

**Provide:** optional `variant` (`lockup` | `mark`), `tone` (`auto` | `night` | `day` | `mono`; default `auto` follows the page theme; mono inherits `currentColor`), `height` (lockup height in px, default 40), `size` (mark width in px, default 44), `href`.

- Leave `tone` on `auto` in themed pages; force `night` or `day` only when the logo sits on a ground opposite to the theme. Use `mono` only where color is impossible (single-ink print, embossing).
- In a site header, use the lockup at 28 to 36px tall. Use `variant="mark"` only where the name already appears nearby or space is square.
- Clear space is one sun diameter on every side. Minimum lockup height 20px; minimum mark width 24px.
- Never recolor the gradient, rotate the limb, set the wordmark in live text, or move the sun off the i. For files, use the Logos asset group.
