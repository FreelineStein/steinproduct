# Font licenses

All faces here are licensed under the SIL Open Font License 1.1 (free for commercial use, embedding and self-hosting). Files are Latin subsets from Fontsource.

- Anybody Semi-Condensed (700, 800): headlines. Static instances of the Anybody variable font at width 90. OFL 1.1.
- Instrument Sans (400, 500, 600): body and UI. OFL 1.1.
- Archivo Expanded (500, 600): the signal face (eyebrows, tags, numbers). Static instances of Archivo at width 125. OFL 1.1.
- Anybody Condensed ExtraBold (width 75) is used only inside the logo artwork, as outlined paths; no font file is needed.
