# Font licenses

All faces here are licensed under the SIL Open Font License 1.1 (free for commercial use, embedding and self-hosting). Files are the Latin subsets published by Fontsource.

- Unbounded (500, 700): headlines. OFL 1.1.
- Instrument Sans (400, 500, 600): body and UI. OFL 1.1.
- Archivo Expanded (500, 600): the signal face (eyebrows, tags, numbers). Static instances of Archivo at width 125, cut from the OFL variable font. OFL 1.1.
- Anybody Expanded ExtraBold is used only inside the logo artwork, as outlined paths; no font file is needed.
